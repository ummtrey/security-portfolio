# Writeups

Sanitized writeups of findings and testing exercises.

**Disclosure policy:** Only findings that are resolved *and* where the program
permits public disclosure are written up here. All target names, hostnames,
endpoints, and identifiers are redacted. These are published as methodology and
learning examples, not to expose any specific program.

Use [`_TEMPLATE.md`](./_TEMPLATE.md) as the starting point for new writeups.
